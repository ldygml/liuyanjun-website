个人网站 后台管理

使用说明：编辑下方表单修改网站内容。电脑端：点“保存到网站”写入本地 js/content.js，再双击 更新线上.bat 发布；手机端：直接打开本页线上地址（https://ldygml.github.io/liuyanjun-website/admin.html），填好下方任一发布配置后，点“保存并发布到线上”即可。建议先点“导出 JSON 备份”留个底。

●照片上传

在手机上选照片，自动压缩后上传到线上仓库。上传后需要“保存并发布到线上”才会在网站生效（发布前请先在 GitHub 直连发布里保存过令牌）。

相册照片：在下方“生活瞬间（相册）”的每条照片右侧点“上传”，会自动填好图片路径。

●GitHub 直连发布（推荐）

不依赖 Vercel，直接通过 GitHub API 更新线上仓库（api.github.com 国内访问稳定）。需要创建一个只允许读写 liuyanjun-website 仓库内容文件的受限令牌。

●Vercel API 发布（备选）

通过自建后台接口发布。需要先部署 admin-api 到 Vercel 并填写 API 地址和密码，部署方法见 admin-api 仓库的 README。
